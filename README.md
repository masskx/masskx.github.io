Personal portfolio of **Shuai Ma**, focused on RAG, AI agents, research engineering, and hyperspectral remote sensing.

## Local development

```bash
bundle install
bundle exec jekyll serve
```

This site is built with the open-source [al-folio](https://github.com/alshedivat/al-folio) academic portfolio template and deployed with GitHub Pages.
