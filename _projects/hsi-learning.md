A beginner-friendly Chinese-language path for hyperspectral image classification, built around the Indian Pines dataset. It runs from data loading and visualization through classical ML baselines (SVM) to 1D/2D/3D CNN, HybridSN, SSRN, and Transformer models, with notebooks, training scripts, and reusable Python modules.

<details markdown="1">
<summary>中文介绍</summary>

面向高光谱图像分类学习者的中文教学型仓库。当前以 Indian Pines 数据集为主线，从数据读取、可视化和传统机器学习基线逐步走向深度学习模型。

学习内容覆盖 SVM、1D/2D/3D CNN、HybridSN、SSRN 和 Transformer，并同时提供 Notebook、脚本化训练入口和可复用 Python 模块。
